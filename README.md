# Schematic Brush Database

Schematic Brush Database is an add-on for [Schematic Brush Reborn](https://github.com/eldoriarpg/SchematicBrushReborn).
It stores saved brushes and presets in a MariaDB, MySQL or PostgreSQL database, so several servers share them.

Everything else is in the [documentation](https://docs.eldoria.de/schematic-brush-reborn/database).

## Requirements

| What | Version |
|---|---|
| Server | Paper 1.21.11 or newer |
| Java | 25 |
| Other plugins | Schematic Brush Reborn 3 |
| Database | MariaDB, MySQL or PostgreSQL |

Use version 1.1.10 with Schematic Brush Reborn 2.
