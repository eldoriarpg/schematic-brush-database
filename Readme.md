# What is SchematicBrushDatabase
SchematicBrushDatabase is an Add-On for [Schematic Brush Reborn](https://github.com/eldoriarpg/SchematicBrushReborn).

It synchronizes saved brushes and presets between multiple servers via a MariaDB, MySQL or PostgreSQL database.

Version 2 requires Schematic Brush Reborn 3 on Paper 1.21.11 or newer. Use version 1.1.10 with Schematic Brush Reborn 2.
A database that was last used with a version before 1.1 has to be started with 1.1.10 once before updating to version 2.

Take a look at the [wiki](https://github.com/eldoriarpg/schematic-brush-database/wiki) for more information.
